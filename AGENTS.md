# Workspace Guidelines: Event Jam UI

## Ultimate Premium UI/UX & Product Design System (2026)

This project follows the **Ultimate Premium UI/UX & Product Design System**. When developing or modifying user interfaces:

### 1. Design Standard
- **Aesthetic**: Event Jam Electric Editorial & Apple HIG Craftsmanship.
- **Palette**: Dark cobalt canvas (`#080808`, `#12141D`), Electric Lime highlights (`#DAFB71`), Royal Blue accents (`#0042D9`), Pale lavender/blue tints (`#EBF1FF`), Coral alerts (`#EE3D5A`).
- **Typography**: Modern geometric display (`Lufga`, Inter, system fallback) with strict proportional leading and tracking.
- **Materials**: Specular liquid glass capsules with fine semi-transparent borders and subtle shadows.

### 2. Engineering & Quality
- **Technology**: Vanilla CSS + React 19 + Motion for React (spring physics). No Tailwind unless requested.
- **All Interactive Elements Function**: Every button, chip, search field, sheet, and modal must have real state, transitions, or feedback.
- **Accessibility & Motion**: WCAG 2.2 AA compliance, touch targets ≥ 44×44px, and `prefers-reduced-motion` compliance.
